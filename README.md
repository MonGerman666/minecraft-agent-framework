# Minecraft Agent Framework

Aquest projecte crea agents que poden interactuar amb un servidor de Minecraft.

## Configuració
1. Instal·la Python 3.
2. Executa el servidor de Minecraft.
3. Assegura’t que tens la carpeta `mcpi` al directori del projecte.

## Executar el projecte
Fes servir el següent comandament:
```bash
python main.py
